# Obsidian 知识库落地包

**2026-09-20｜技术设计 + 实施手册 + 开发任务 + 人工试点模板**

这不是一键安装的软件包。现在可以使用 `starter-vault` 开始人工剪藏和整理；自动导入、AI 编译、预算、服务、插件和 MCP 需要按开发计划实现。

## 一条主线

新建 Knowledge-Pilot → 30 份资料/20 个问题 → 离线词法资料库 → 受控 AI 提案 → 人工审核 → 恢复/预算/撤回验收 → 日常使用。不要同时安装多个自动写 Vault 的插件，也不要先把全量个人资料发给模型。

初始源码只需 apps/service、apps/obsidian-plugin、apps/cli、packages/contracts 四个工作区。原始资料、源码和运行数据库分别放在不同目录。

## 包内内容边界

starter-vault 是可直接打开的普通 Markdown，没有隐藏插件和执行脚本。fixtures 中的 DemoKV 是虚构测试系统，不是真实产品资料，也不是用户实际决定。references 只包含合同/DDL，局部语法检查不证明业务已实现。

所有费用数字是示例限额；所有工程工时是有条件规划，不是交付日期。正式选择模型、插件、依赖版本和同步方式时要记录实际基线。
