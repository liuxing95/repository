## 哪些是本方案自己的设计

目录布局、TypeScript 合同、SQL 表、HTTP 路由、插件名称、操作命令、预算上限、任务状态、试点数量、页数限制、工程工时和验收阈值均为本方案定义。没有对应的上游“官方默认值”之意。

设计附件的 schema/DDL 可检查，不代表应用级校验、权限、恢复和物理存储安全都由这些表自动提供。公开资料能证明 API 形状，不能代替真实 Obsidian、模型或目标 OS 集成测试。
