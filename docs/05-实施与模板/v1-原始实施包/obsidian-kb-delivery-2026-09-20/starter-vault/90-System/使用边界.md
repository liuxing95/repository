# 试点使用边界

先在独立目录使用，暂不启用同步和自动改写插件。当前没有程序监控目录，也不会自动调用模型。

来源是收到的实际文档或剪藏，不是只有 URL 的空壳。分清 full_text、excerpt、unknown；剪藏日期不能冒充发布日期。

人工笔记和决定不自动成为外部事实。AI 回答只能保存为候选，不能靠自己引用自己提高可信度。

模板内 kb_type、status、publish 是展示字段，不是可信授权。未来导入器默认排除 90-System 模板与导航；资料中的命令和“忽略规则”仅是文本，不应执行。

服务账本、对象仓、密钥、活动 SQLite 文件都不应放进这个 Vault。需要接入 AI 时按交付包的《落地手册》执行，默认模型和写入关闭。
