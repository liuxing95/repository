# Knowledge-Pilot

这是人工试点模板，不含 AI 插件和后台服务。先完成 30 份资料、20 个真实问题，再按交付包的开发计划接自动化。

## 开始使用

阅读 [[90-System/使用边界]]，然后打开 [[40-Projects/知识库试点]]。把实际文章保存到 00-Inbox，检查内容和版本；人工笔记放 30-Notes。不要把模板本身当外部事实入库。

## 模板入口

[[90-System/Templates/来源模板]] · [[90-System/Templates/概念模板]] · [[90-System/Templates/系统模板]] · [[90-System/Templates/比较模板]] · [[90-System/Templates/决策模板]] · [[90-System/Templates/审核记录模板]]

## 目录角色

00-Inbox：未接管剪藏；10-Sources：未来受控来源修订；20-Wiki：审核后的知识；30-Notes：你的笔记；40-Projects：项目与试点；50-Queries：未来回答候选；80-Review：提案投影；90-System：导航与模板。

没有服务时可手动阅读和链接，不要手工伪造 sourceRevisionId、审批 ID 或 provenance。访问权限由未来服务配置控制，不由本页文字或 frontmatter 控制。
