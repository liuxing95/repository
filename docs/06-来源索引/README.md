# 来源索引怎么用

[汇总目录](来源入口汇总.md)和 [JSON](sources-index.json)将各轮引用入口归并，并记录出现文档。它们不取代原报告的证据等级与局限说明。

初始的 [50 条来源记录](../02-完整调研/原始调研包/Obsidian-KB-Report/sources/sources.json)按原样保留。后续材料中的 `[S01]` 等标签只在本文件内有效，不同文档同名标签可能指向不同来源，因此统一索引使用新的 `U...` 号并保留原文件定位。

本包不包含全部网页全文、论文全文或第三方仓库源码。X 原长文只有部分读取；部分源页面曾有截断或版本快照差异；不能因存在引用链接就声称完成整站、全仓或全文审查。

本次任务是汇编，未发起新的网络验证。正式实施前复验采用的版本、API、许可证和目标环境；检索结果、项目自述和本方案设计仍应分别看待。
