# 场景 12 验证记录（2026-09-24）

本记录只代表 2026-09-24 这一轮本机验证，不覆盖公网部署。受测环境：macOS、Node.js 24.14.1、pnpm 10.33.0、Obsidian 1.13.7；Docker 由本机 OrbStack 提供，固定镜像是 README 中带 SHA-256 摘要的 `node:24.14.1-alpine`。

| 检查 | 本轮结果 | 证明的边界 |
|---|---|---|
| `pnpm check` | 通过：类型、lint、196 个常规测试、2 个编译产物测试；8 个环境专项默认跳过 | 新 HTTP、策略、发布账本和已有场景回归 |
| `pnpm test:oci` | 通过：6 个测试 | 固定 OCI 镜像的无网络隔离、真实 Wiki → 构建 → 本机站点 → 来源撤回，以及最终文件哈希一致 |
| `pnpm test:desktop` | 通过 | 真实 Obsidian 加载插件、连接、主端、设置页及原有冒烟流程；新增公开副本区能正常渲染 |
| 定向发布测试 | 通过：10 个常规测试；OCI 另计 2 个 | 私密依赖默认阻断、受控文本附件、HTML 转义、只读草稿、摘要批准、错误字节、部分写入重试、受权回退、来源撤回 |

插件新入口截图：[公开副本设置页](evidence/publication-entry.png)。截图来自独立测试 Vault，没有真实来源正文、密钥或配对码。

验证过的失败行为：未处理链接不能构建；非 HTTPS 替换被拒绝；未批准或摘要不匹配不能发布；保存的最终文件被改动后不能发布；部分上传只确认哈希正确的文件，沿同一 release 重试未确认项；来源撤回后无法再读取相关预览，当前本机入口及相关 release 目录被移除。备份目录扫描不会沿 `public-site/current` 符号链接进入站点投影；批准字节仍保存在 SQLite 中。

本轮没有配置真实公网站点、远端认证、CDN 或搜索引擎清理，因此不能把 `published-local` 解读成“已公开到互联网”。当前内置静态构建器输出保留换行的纯文本页面；没有 Quartz、PandaWiki、图片或 PDF 附件适配器。桌面冒烟验证了新入口渲染，完整的选择—批准—发布链路由真实 OCI 服务集成测试覆盖，并非在真实 Obsidian 中逐按钮完成。上线公网前还需明确目标、认证、缓存和下架责任，并针对该目标另做端到端验收。
