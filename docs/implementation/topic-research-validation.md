# 场景 05：实施与验收记录

日期：2026-09-22。使用、代码和恢复说明见[课题研究与报告](topic-research-report.md)。本记录区分本地流程、受信适配器工程验证和真实模型验收。

## 本轮交付

- 确认课题与问题清单，检查项目版本依据，区分历史公开时间资格。
- 固定研究快照，明确确认差异，按问题展示覆盖、反证线索和缺口。
- 库内模式不发网络；用户指定缺口入口时复用收录器，累计限制发现和材料，不把未提交材料用于报告。
- 分章原文整理、受信模型接口、根费用及调用上限、取消与迟到费用结算。
- 不可变报告及费用摘要，完整报告经场景 04 审核保存，Wiki 提升另行批准。
- schema 5 私有备份与迁移，README、接手指南和导航同步更新。

真实模型尚未配置。测试适配器使用固定费用及输出，只验证调用合同；不能据此宣布真实模型质量、实际费用或自由综合写作已验收。报告机械检查与人工语义审阅分别显示，方案 RSH3 保持未完成。

## 自动化验证

第一轮发现研究作业类型尚未加入公共合同，修复后 14 项研究／迁移测试通过。随后增加课题总范围校验的失败用例，先确认其确实失败，再修复；同时补充界面修改草案时旧异步响应不能恢复确认控件的测试。

`pnpm check` 首轮通过：常规测试 100 通过、5 个环境专项跳过；编译后真实进程 2 项通过。追加根材料预留转换后，相关 10 项专项通过。最后补上报告正文与候选证据清单的绑定、模型未解决项达到上限时仍能冻结报告的回归测试。

最终代码在仓库根目录执行：

```bash
pnpm typecheck
pnpm lint
KB_TEST_OCI=1 KB_TEST_BUILT=1 pnpm test
pnpm test:desktop
```

类型检查和 lint 通过。最终回归为 **106 项通过、2 项跳过**，40 个测试文件通过、1 个文件跳过，耗时 45.52 秒；包含 OCI 隔离和编译后真实服务进程。两项跳过属于真实语料专项，本轮没有启用 `KB_TEST_CORPUS`。本次结果不能关闭之前记录的真实语料问题。

真实 Obsidian 1.13.7 桌面检查 **21 项通过，页面错误 0**。新增路径覆盖课题确认、快照确认、生成章节、冻结报告、经场景 04 审核保存完整正文，以及取消后保留报告。脚本比对候选区文件与冻结报告的完整内容。桌面使用原文整理，没有启用真实模型。

证据：[桌面检查清单](evidence/research-desktop-checks.json)、[研究报告截图](evidence/research-report.png)。当前分支的完整顺序审查及修复记录见[审查记录](../../.context/compound-engineering/ce-review/2026-09-22-topic-research/review.md)。按照仓库工具映射，审查在主线程完成，不属于独立子 agent 审核。

## Post-Deploy Monitoring & Validation

负责人：隔离试点的主端操作者。验证窗口：升级后的首次研究、首次快照推进、首次候选保存，以及前 10 个章节尝试。服务和插件一起更新。

先只读核对：

```sql
PRAGMA user_version;
PRAGMA integrity_check;
SELECT json_extract(value,'$.state') AS state,count(*) FROM research_jobs GROUP BY state;
SELECT research_id,count(*) FROM research_chapters GROUP BY research_id;
SELECT root_id,state,count(*),sum(actual),sum(reserved) FROM calls GROUP BY root_id,state;
SELECT kind,count(*) FROM events WHERE kind LIKE 'research.%' GROUP BY kind;
SELECT r.id FROM research_reports r LEFT JOIN research_snapshots s ON s.id=json_extract(r.value,'$.snapshotId') WHERE s.id IS NULL;
```

健康信号：schema 为 5，完整性为 `ok`，报告的最终快照存在；无模型研究不新增收费调用；取消后章节不再增加，已发生费用仍可结算；没有批准的报告不出现在候选区文件中。注意 `research-budget` 作业成功仅表示预算容器建立。

出现越界获取、跨根拆分费用、未确认推进快照、撤回正文仍可读取或未批准写文件，应停止新研究和写入，保留账本、Vault 与复现时间。不要删除 `calls`、`roots`、报告或回执来恢复额度。迁移前备份只在独立副本核对；旧服务不能直接写 schema 5，更不能用旧备份覆盖本轮新费用和记录。

## 未验证的范围

本轮不含真实模型语义支持率、提供方实际价格回执和开放领域报告效果，不运行模型或收费搜索。补采的新增编排用固定获取响应验证边界，实际网络获取与解析沿用场景 02；网络可用性不能由固定响应推断。库内流程在本次桌面验证中单独记录。场景 04 已记录的历史语料失败不被本轮较小范围的成功覆盖。
